## Selenium помогает искать информцию в Википедии

---
### Описание программы

Программа умеет искать данные в Википедии. При запуске программы она открывает
браузер и главную страницу Википедии. После этого в консоли появляется запрос
*«Что вы хотите узнать?»*. Затем, после того как вы введете данные, программа
ищет нужную информацию в Википедии. После того как статья найдена, можно выбрать 
одну из трёх опций:

1. Прокрутка страницы вниз, чтобы просмотреть всю что на ней есть;
2. Переход на одну из связанных страниц (страница выбирается случайным образом);
3. Выход из программы.

Программа может переходить по связанным страницам, пока не достигнет страницы у которой больше нет связанных.
Обычно 3-4 перехода. После этого можно продолжить искать нужную информацию. Или выйти из программы.

---
### Использование программы

Для работы с программой необходимо произвести запуск файла main.py и подождать несколько секунд пока не
откроется окно браузера, а в консоли не появится запрос *«Что вы хотите узнать?»* В процессе работы нельзя
закрывать окно браузера, иначе программа при выборе опции 1 или 2 выдаст ошибки в консоль.

---
### Технологии

- Работа программы осуществляется с помощью библиотеки Selenium и её компонентов:
  - webdriver;
  - WebDriverException;
  - Keys;
  - By.
- Сообщения об ошибках выводлятся с помощью средств библиотеки Tkinter;
- Выбор связанных станиц для перехода осуществляется с помощью функции choice из библиотеки random.
